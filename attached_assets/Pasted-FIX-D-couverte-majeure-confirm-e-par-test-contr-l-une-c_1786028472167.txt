Dans server/services/carrier-service.ts, fonction `buildVitipsPayload`,
ajouter une fonction de nettoyage et l'appliquer aux champs texte :

```ts
function sanitizeArabicText(input: string | null | undefined): string {
  if (!input) return "";
  return input
    // Retire les marques de direction de texte (RTL/LTR marks) et autres
    // caractères de contrôle Unicode invisibles souvent injectés par des
    // exports/API tierces (YouCan, etc.).
    .replace(/[\u200B-\u200F\u202A-\u202E\u2060-\u2064\uFEFF]/g, "")
    // Normalise Unicode en forme composée (NFC) — élimine les différences
    // entre lettre+diacritique combiné vs décomposé, invisibles à l'affichage.
    .normalize("NFC")
    // Espaces insécables / espaces Unicode variés → espace normal.
    .replace(/[\u00A0\u2000-\u200A\u202F\u205F\u3000]/g, " ")
    // Espaces multiples → un seul, trim.
    .replace(/\s+/g, " ")
    .trim();
}
```

les fixes précédents) :
