POST /api/stock/fix-historical-shipments

This endpoint finds all orders that were shipped (status IN: 'Attente De Ramassage', 'transit', 'delivered', 'refused', 'Retour Recu', 'En Cours De Retour') 
but whose stock was never decremented (no stockMovement with type='shipped' for that orderId).

Logic:
1. Get all orders for storeId where status IN ('Attente De Ramassage', 'transit', 'delivered', 'refused', 'Retour Recu', 'En Cours De Retour')
2. For each order, check if a stockMovement with orderId = order.id and type = 'shipped' already exists
3. If NO stock movement exists → this order's stock was never decremented → add to "pending" list
4. Return the pending list with preview (orderId, orderNumber, customerName, products, quantities)

GET /api/stock/fix-historical-shipments/preview
- Returns: { count: number, orders: [{id, orderNumber, customerName, items: [{productName, qty, productId}]}] }

POST /api/stock/fix-historical-shipments/apply
- Body: { orderIds: number[] } — optional, if empty apply to ALL pending
- Calls decrementStockForOrder() for each pending order
- Returns: { applied: number, skipped: number, errors: string[] }
