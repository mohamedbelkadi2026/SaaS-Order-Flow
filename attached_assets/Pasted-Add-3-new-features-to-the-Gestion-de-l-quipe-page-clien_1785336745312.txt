BACKEND:
Add new endpoint: GET /api/agents/comparison-by-product

This returns for each product, each agent's confirmation rate:
SELECT 
  p.id as product_id,
  p.name as product_name,
  o.assigned_to_id as agent_id,
  COUNT(*) as total,
  COUNT(*) FILTER (WHERE o.status IN ('confirme','expédié','delivered','Attente De Ramassage')) as confirmed
FROM orders o
JOIN products p ON o.product_id = p.id  
WHERE o.store_id = $storeId AND o.assigned_to_id IS NOT NULL
GROUP BY p.id, p.name, o.assigned_to_id
