Fix the "Choisir la plateforme" dropdown in the Magasins modal (client/src/pages/magasins.tsx).

PROBLEM:
The dropdown shows "Aucun résultat" even though YouCan and other integrations are connected.

ROOT CAUSE:
In magasins.tsx around line 530:
  const { data: storeIntegrations } = useIntegrations("store");

This fetches integrations with type="store". But the data might be empty or the items are not mapped correctly.

The platformItems is built like this (line 278):
  const platformItems = (storeIntegrationsList || []).map((s: any) => ({
    value: s.provider,
    label: s.provider,
  }));
