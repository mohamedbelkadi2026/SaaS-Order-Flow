VITIPSEXPRESS API DOCUMENTATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Base URL: https://app.vitipsexpress.com/api/client
Auth: Header "API Token: {token}" + "Accept: application/json"

Endpoints:
- GET  /colis/track/{code}         → track a package by code
- POST /post/colis/add-colis       → create a shipment
- GET  /colis/list-colis-ramassage → list parcels awaiting pickup
- GET  /colis/list-colis/          → list all parcels
- GET  /list-status                → list all statuses
- GET  /villes                     → list cities { data: [{name, abbr}] }

Track response:
{ "data": [ { "status": "Collected", "Date_Evenement": 1723991095 }, ... ] }
→ Use the FIRST item in data array as current status

Create shipment (POST /post/colis/add-colis) body:
{
  fullname: string,        // customer name (required)
  phone: string,           // customer phone (required)
  city: string,            // city abbr from /villes (required)
  address: string,
  price: number,           // COD amount (required)
  product: string,         // product name(s) comma-separated (required)
  qty: string,             // quantities comma-separated (required)
  note: string,
  exchange: 0,             // always 0
  openpackage: 0,          // always 0
  from_stock: 0,
  try_product: 0,
  internal_id: string      // our order number
}
Response: { "code": "ok", "message": "The package has been successfully added" }
→ The package code returned is in the response — save it as trackNumber

Status mapping from Vitipsexpress → platform status:
"Delivered" → "delivered"
"Collected" → "Attente De Ramassage"
"Awaiting pickup" → "Attente De Ramassage"
"Waiting for pickup" → "Attente De Ramassage"
"Received" → "transit"
"Received by courier" → "transit"
"Ready for Shipment" → "transit"
"Shipped" → "transit"
"Traveling" → "transit"
"Distribution" → "transit"
"Distributed" → "transit"
"Tracking Request" → "transit"
"Refused" → "refused"
"Cancel" → "refused"
"Postponed" → "unreachable"
"Scheduled" → "unreachable"
"no response 1" → "unreachable"
"no response 2" → "unreachable"
"no response 3" → "unreachable"
"unreachable" → "unreachable"
"out of zone" → "unreachable"
