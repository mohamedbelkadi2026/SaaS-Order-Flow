CAUSE (confirmée dans le code)
server/routes.ts, endpoint `/api/stats/filtered` (~ligne 1020-1030) :
```ts
const profResult = await computeProfitability(storeId, { ... });
const netProfit = Math.round(profResult.totals.netProfit * 100);
```
`profResult.totals.netProfit` (le champ retourné par `computeProfitability`,
partagé avec Profit Analyzer Pro) NE SOUSTRAIT PAS les dépenses
publicitaires — malgré son nom, c'est un profit "avant Pub" (Revenu − Coût
produits − Frais livraison − Emballage − Commissions). "Rentabilité
Avancée" soustrait le Pub EN PLUS, séparément, pour obtenir son "Profit Net
Final" (= Revenu − Coûts livrées − Pub). Résultat : deux définitions
différentes affichées sous le MÊME libellé "Profit Net" selon la page.

FIX — Faire en sorte que le Dashboard soustraie lui aussi le Pub, pour que
"Profit Net" représente partout la même définition complète (après
publicité), cohérente avec Rentabilité Avancée.

par :
```ts
const profResult = await computeProfitability(storeId, {
  dateFrom:  profDateFrom,
  dateTo:    profDateTo,
  dateRange: (!profDateFrom && !profDateTo) ? 'all' : undefined,
});
// computeProfitability returns values in DH; dashboard formatCurrency expects centimes.
// IMPORTANT : profResult.totals.netProfit est un profit "avant Pub" (n'inclut
// pas les dépenses publicitaires). On soustrait adSpendTotal (déjà en
// centimes) pour obtenir le VRAI profit net final, cohérent avec la formule
// affichée sur Rentabilité Avancée ("= Revenu – Coûts livrées – Pub").
const profitBeforeAds = Math.round(profResult.totals.netProfit * 100);
const netProfit = profitBeforeAds - adSpendTotal;
const roas = adSpendTotal > 0 ? revenue / adSpendTotal : 0;
const roi = adSpendTotal > 0 ? (netProfit / adSpendTotal) * 100 : 0;
```

(La formule de `roi` reste `netProfit / adSpendTotal`, mais utilise
maintenant le VRAI net profit après Pub — vérifier que ce chiffre de ROI
reste cohérent avec l'attente métier ; si besoin d'un ROI basé sur le profit
AVANT Pub, garder une variable séparée `profitBeforeAds` pour ce calcul
précis plutôt que `netProfit`.)
