## Ajustement 1 — Format plus compact
Actuellement affiché : "اختر اللون المناسب لك: الأخضر | اختر القياس المناسب لك: XL" (répète la question en entier).
Souhaité : juste les valeurs choisies, compact, du style "الأخضر / XL".

Dans server/routes.ts, remplacer la construction de youcanVariantLabel par une version qui ne garde que les valeurs (déjà disponibles dans v.variant?.values, confirmé par le log [VARIANT-CONTENT] précédent : values= ["الأسود","M"]) :
```ts
const variationValues = Array.isArray(v.variant?.values) ? v.variant.values : null;
let youcanVariantLabel: string | null = null;
if (variationValues && variationValues.length > 0) {
  youcanVariantLabel = variationValues.join(' / ');
} else {
  const variations = v.variant?.variations;
  if (variations && typeof variations === 'object' && Object.keys(variations).length > 0) {
    youcanVariantLabel = Object.values(variations).join(' / ');
  }
}
```
Résultat attendu pour ce test : "الأخضر / XL".
