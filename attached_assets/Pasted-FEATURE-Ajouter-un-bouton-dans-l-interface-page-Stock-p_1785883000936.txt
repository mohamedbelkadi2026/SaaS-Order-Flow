ÉTAPE 1 — client/src/pages/inventory.tsx : bouton + mutation + dialog de
résultat

Ajouter, à côté du bouton existant "Nettoyage intelligent" (en haut de la
page Stock, visible dans le screenshot fourni), un nouveau bouton :

```tsx
const [backfillResult, setBackfillResult] = useState<any>(null);
const backfillHistoryMutation = useMutation({
  mutationFn: () => apiRequest("POST", "/api/products/backfill-initial-stock-history", {}).then(r => r.json()),
  onSuccess: (data) => {
    setBackfillResult(data);
    qc.invalidateQueries({ queryKey: ["/api/products"] }); // rafraîchir la liste + les historiques déjà ouverts
    toast({ title: "✅ Historique réparé", description: data.message });
  },
  onError: (e: any) => toast({ title: "Erreur", description: e.message, variant: "destructive" }),
});
```

```tsx
<Button
  variant="outline"
  onClick={() => backfillHistoryMutation.mutate()}
  disabled={backfillHistoryMutation.isPending}
  data-testid="button-backfill-stock-history"
>
  {backfillHistoryMutation.isPending ? (
    <><Loader2 className="w-4 h-4 mr-2 animate-spin" /> Réparation en cours...</>
  ) : (
    <><History className="w-4 h-4 mr-2" /> Réparer l'historique des stocks</>
  )}
</Button>
```

(Adapter l'import de l'icône `History` depuis `lucide-react` si pas déjà
importée dans ce fichier — sinon utiliser une icône déjà disponible comme
`RefreshCw`.)

ÉTAPE 2 — Dialog affichant le détail du résultat (produits/variantes
corrigés)

```tsx
<Dialog open={!!backfillResult} onOpenChange={(v) => !v && setBackfillResult(null)}>
  <DialogContent className="sm:max-w-lg max-h-[80vh] overflow-y-auto">
    <DialogHeader>
      <DialogTitle>Réparation de l'historique des stocks</DialogTitle>
      <DialogDescription>{backfillResult?.message}</DialogDescription>
    </DialogHeader>
    {backfillResult?.details?.length > 0 ? (
      <div className="space-y-2">
        {backfillResult.details.map((d: any, i: number) => (
          <div key={i} className="flex justify-between items-center text-sm border-b pb-1.5">
            <span className="truncate max-w-[60%]">{d.name}</span>
            <span className="text-emerald-600 font-semibold">+{d.quantity}</span>
            <span className="text-xs text-muted-foreground">
              {new Date(d.date).toLocaleDateString('fr-FR')}
            </span>
          </div>
        ))}
      </div>
    ) : (
      <p className="text-sm text-muted-foreground">Aucune entrée manquante trouvée — tout est déjà à jour.</p>
    )}
  </DialogContent>
</Dialog>
```
