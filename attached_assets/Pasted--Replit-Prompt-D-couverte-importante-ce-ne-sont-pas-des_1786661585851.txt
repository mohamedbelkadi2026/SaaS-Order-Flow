# Replit Prompt — Découverte importante : ce ne sont pas des "variantes" mais des questions personnalisées YouCan

## Nouvelle info clé

En passant une commande de test réelle (YC-011, "test", Taroudant), la page de confirmation YouCan montre clairement :
```
اختر اللون المناسب لك : الأحمر   (Choisissez la couleur qui vous convient : Rouge)
اختر القياس المناسب لك : M       (Choisissez la taille qui vous convient : M)
```
Ce format "Question : Réponse" correspond aux champs de formulaire personnalisés (custom fields / custom questions) que YouCan permet de configurer sur une fiche produit — PAS au système de variantes produit standard (variant.name/variant.sku) qu'on supposait dans les prompts précédents. C'est pour ça que rien de ce qu'on a essayé jusqu'ici n'a fonctionné : on cherchait au mauvais endroit dans le payload.

Autre indice : la colonne "INFOS SUPPLÉMENTAIRES" existe déjà dans le tableau Suivi des Colis/Nouvelles (visible, actuellement vide "—" pour cette commande) — elle est probablement prévue exactement pour ce genre de données, mais rien ne l'alimente aujourd'hui.

## Ce que je veux

Si besoin, garde/ajoute le console.log('[YOUCAN-PAYLOAD-DEBUG]', JSON.stringify(payload, null, 2)) sur le payload COMPLET de la commande (pas juste les line items cette fois — les custom fields sont probablement au niveau de la commande ou de la ligne d'article, mais dans un champ du type custom_fields, additional_fields, form_answers, questions, attributes, ou similaire).
2. Colle-moi le JSON complet retrouvé pour cette commande précise, pour qu'on voie exactement où YouCan range "اختر اللون المناسب لك : الأحمر" et "اختر القياس المناسب لك : M".
