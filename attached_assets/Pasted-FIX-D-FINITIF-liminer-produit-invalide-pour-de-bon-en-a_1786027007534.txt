ÉTAPE 1 — Endpoint de diagnostic : tester la création d'un produit via API

```ts
app.post("/api/debug/vitips-try-create-product", requireAuth, requireAdmin, async (req: any, res: any) => {
  const storeId = req.user!.storeId!;
  const accts = await db.select().from(carrierAccounts)
    .where(and(eq(carrierAccounts.storeId, storeId), eq(carrierAccounts.carrierName, "vitipsexpress")));
  if (accts.length === 0) return res.status(404).json({ message: "Aucun compte Vitips connecté" });
  const apiKey = accts[0].apiKey;
  const testProductName = String(req.body.productName || "Produit Test API");

  const axios = (await import("axios")).default;
  const candidates = [
    { url: "https://app.vitipsexpress.com/api/client/post/produit/add-produit", body: { title: testProductName, code: "TEST-API-001" } },
    { url: "https://app.vitipsexpress.com/api/client/post/produit/add-produit", body: { name: testProductName, code: "TEST-API-001" } },
    { url: "https://app.vitipsexpress.com/api/client/post/product/add-product", body: { title: testProductName, reference: "TEST-API-001" } },
    { url: "https://app.vitipsexpress.com/api/client/produit/add", body: { title: testProductName } },
    { url: "https://app.vitipsexpress.com/api/client/product/add", body: { title: testProductName } },
  ];

  const results: any[] = [];
  for (const c of candidates) {
    try {
      const resp = await axios.post(c.url, c.body, {
        headers: { "api-token": apiKey, "Accept": "application/json", "Content-Type": "application/json" },
        timeout: 10_000, validateStatus: () => true,
      });
      results.push({ url: c.url, sentBody: c.body, status: resp.status, response: resp.data });
    } catch (err: any) {
      results.push({ url: c.url, sentBody: c.body, error: err.message });
    }
  }
  res.json({ results });
});
```

Appeler une fois déployé (console navigateur) :

ÉTAPE 2 (À FAIRE UNE FOIS L'ÉTAPE 1 CONFIRMÉE) — Auto-enregistrer le produit
AVANT chaque tentative d'expédition, si Vitips le rejette

Dans le flux d'expédition Vitips (`buildVitipsPayload` / l'appel vers
`add-colis`), quand la réponse est `{"code":"ko","error":"produit
invalide"}` :
1. Appeler l'endpoint de création de produit découvert à l'ÉTAPE 1 avec le
   nom exact du produit de la commande.
2. Si la création réussit, RÉESSAYER immédiatement l'envoi du colis (une
   seule fois, pas de boucle infinie).
3. Si la création échoue aussi, laisser l'échec remonter normalement
   (comme aujourd'hui).

```ts
async function shipToVitipsWithAutoRegister(payload: any, apiKey: string): Promise<any> {
  let resp = await axios.post("https://app.vitipsexpress.com/api/client/post/colis/add-colis", payload, {
    headers: { "api-token": apiKey, "Content-Type": "application/json" }, validateStatus: () => true,
  });
  if (resp.data?.code === "ko" && resp.data?.error === "produit invalide") {
    console.log(`[VITIPS-AUTO-REGISTER] Produit "${payload.product}" invalide — tentative de création automatique...`);
    try {
      await axios.post("<URL_CONFIRMÉE_ÉTAPE_1>", { title: payload.product /* + champs confirmés étape 1 */ }, {
        headers: { "api-token": apiKey, "Content-Type": "application/json" }, validateStatus: () => true,
      });
      console.log(`[VITIPS-AUTO-REGISTER] Produit créé, nouvel essai d'expédition...`);
      resp = await axios.post("https://app.vitipsexpress.com/api/client/post/colis/add-colis", payload, {
        headers: { "api-token": apiKey, "Content-Type": "application/json" }, validateStatus: () => true,
      });
    } catch (regErr: any) {
      console.error("[VITIPS-AUTO-REGISTER] Échec création produit:", regErr.message);
    }
  }
  return resp;
}
```

Remplacer l'appel direct `axios.post(".../add-colis", ...)` par
`shipToVitipsWithAutoRegister(payload, apiKey)` aux 2 endroits d'expédition
(bulk-ship et expédition individuelle).
